# Dynamic Post Composer

## Aim
Dynamic Post Composer is a modern React + Vite application built for a college experiment. It allows users to create polished social media posts for multiple platforms while receiving real-time validation and visual feedback.

## Objectives
- Create a responsive and attractive social post composer.
- Support multiple platform rules for Twitter, Instagram, LinkedIn, and Facebook.
- Use React functional components and hooks only.
- Demonstrate clean component structure and production-ready UI.

## Features
- Platform selection cards for multiple social networks.
- Live post textarea with placeholder and word count.
- Character counter with safe, near-limit, and exceeded states.
- Real-time validation for character limits and hashtag requirements.
- Image upload support with preview.
- Publish flow with success alert and form reset.
- Responsive design and dark mode toggle.

## Technology Used
- React
- Vite
- CSS for modern responsive styling

## How to Run
1. Install dependencies:
   ```bash
   npm install
   ```
2. Start the development server:
   ```bash
   npm run dev
   ```
3. Open the Vite URL shown in the terminal.
